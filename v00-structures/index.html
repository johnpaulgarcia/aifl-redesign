Concept 00 · The Evolution

Ten structures, one design system.

The clean white institutional redesign of aifl.edu.au, re-architected ten ways. Same palette, typeface, content and course data in every file — only the page structure and layout change. For palette experiments, see the ten colourways.

← All concepts

  1. 01Split Hero Full-viewport 50/50 hero (copy left, edge-to-edge photo right), sticky facts rail beside a scrolling list of wide course rows.
  2. 02Course Finder First The hero is a live search panel — type to filter all 15 courses instantly. Journey becomes a swipeable snap strip.
  3. 03Editorial Magazine Six-rem display headline, hairline rules, courses as a numbered directory 01–15, e-book as a subscription panel.
  4. 04Sticky Sidebar Fixed left rail with logo, nav, phone and enquire button; content scrolls beside it with scroll-spy highlighting.
  5. 05Banded Zigzag Centered hero, then strictly alternating white/mist/teal-tint bands, each a reversed two-column zigzag row.
  6. 06Grid-First Slim one-line hero, then the course grid IS the page — dense 3-column with featured wide cards and floating fact chips.
  7. 07Journey-Led Timeline A vertical timeline spine structures the page: Choose, Enquire, Enrol, Study, Graduate as alternating node cards.
  8. 08Type-Led Minimal One narrow 44rem column, five-rem headline, no cards at all — ruled text rows and whitespace do the work.
  9. 09Panel Dashboard App-like rounded panels on a mist canvas: stat tiles, courses as a real table, journey as a tile row.
  10. 10Category Tabs + Layered Hero Headline overlaps a framed photo with floating stat cards; courses grouped under five animated category tabs.
